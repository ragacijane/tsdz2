KAKO GENERISATI JACOCO / COVERAGE IZVESTAJE (pre i posle GUI testova)
=======================================================================

Postoje dva nacina, oba su vazeca po specifikaciji (JUnit + JaCoCo ili
ugradjeni IntelliJ Code Coverage Agent).


1) MAVEN (komandna linija)
---------------------------

pom.xml vec ima podesen jacoco-maven-plugin vezan za "test" fazu
(prepare-agent + report goal), pa je dovoljna jedna komanda.

Osnovna komanda (pokrece SVE testove i generise izvestaj):

    mvn test

Dva testa u OthelloWidgetTest namerno padaju jer otkrivaju prave bagove
u aplikaciji (checkDraw() i hasLegalMoves(int,Spot)). Bez fleg-a ispod,
Maven prekine build cim test padne i JaCoCo izvestaj se NE napravi.
Zato se dodaje:

    mvn "-Dmaven.test.failure.ignore=true" test

(navodnici oko -D su bitni u PowerShell-u, inace ga razbije na dva
argumenta)

Kako napraviti "pre" i "posle GUI" verziju odvojeno - filtrira se koje
test klase da se pokrenu preko -Dtest:

    PRE GUI testova (samo logika):
    mvn "-Dmaven.test.failure.ignore=true" "-Dtest=SpotBoardIteratorTest,OthelloWidgetTest" test

    POSLE GUI testova (sve, bez filtera):
    mvn "-Dmaven.test.failure.ignore=true" test

Maven svaki put PREPISE target/site/jacoco/, pa se taj folder mora
kopirati na stranu pre sledeceg pokretanja, npr:

    cp -r target/site/jacoco reports/jacoco-pre-gui
    (izmeni test skup, ponovo pokreni mvn test)
    cp -r target/site/jacoco reports/jacoco-posle-gui


2) INTELLIJ IDEA (ugradjeni coverage)
--------------------------------------

1. U Project panelu izabrati test klase:
   - za "pre GUI": SpotBoardIteratorTest.java + OthelloWidgetTest.java
     (Ctrl+klik za vise fajlova)
   - za "posle GUI": ceo src/test/java/othello folder (sve klase)

2. Desni klik -> "Run ... with Coverage" (ili ikonica sa stitom pored
   zelenog Run dugmeta).

3. Kad testovi zavrse, s desne strane se otvori Coverage prozor sa
   procentima po klasi.

4. Desni klik na rezultat u Coverage prozoru -> "Generate Coverage
   Report" -> HTML -> izabrati folder gde da se sacuva.

5. VAZNO: kad se "Run with Coverage" pokrene drugi put, IntelliJ pita
   da li da spoji (merge) sa prethodnim rezultatima ili da zameni -
   izabrati "Replace" / ne spajati, inace se pre i posle pomesaju u
   isti broj.
